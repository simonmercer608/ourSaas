# Simon Mercer — Portfolio

Personal portfolio for **Simon Mercer**, Full Stack Developer at **Tier10 Cloud** (Ashburn, Virginia).

## Stack

- React 18 + Vite
- Tailwind CSS
- React Icons

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit `src/data/portfolio.js` to update bio, experience, projects, and contact links.
